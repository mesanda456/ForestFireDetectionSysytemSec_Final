# 🌲 Smart Forest Guardian

Smart Forest Guardian is a real-time Forest Fire Detection and Monitoring System designed to protect forests and hikers using IoT sensors, Firebase cloud backend, and a Progressive Web Application (PWA).

The system allows:

• Real-time environmental monitoring  
• Fire risk detection  
• Mobile access for hikers  
• Authority control panel  
• Live GPS tracking  
• Installable mobile web application  

---

## 🚀 Project Overview

Forest fires are a major environmental threat. This system uses IoT sensors and cloud-based monitoring to detect potential fire risks early and alert both authorities and hikers in real time.

The project consists of:

1. IoT Monitoring Devices (ESP / Sensors)
2. Firebase Cloud Backend
3. Web Dashboard for Authorities
4. Mobile PWA App for Hikers
